# BriefBoard Extension Features

## 1. 🧠 Smart Page Actions
A grid of pre-defined "Use Cases" allows users to instantly analyze the current web page:
*   **Summarization**: Generates an overview, key points, and conclusion.
*   **Explain Like I'm 5 (ELI5)**: Simplifies complex content into easy-to-understand analogies.
*   **Key Takeaways**: Extracts the core "so what?" insights.
*   **Action Items**: Scans content for tasks or calls to action.
*   **Social Media Post**: Drafts a viral-ready post (LinkedIn/Twitter) based on the page.
*   **Critique & Review**: Analyzes content for bias, fallacies, and strengths.
*   **Text Tools**: Grammar check, Simplify, Shorten/Lengthen, Paraphrase, and Translate.
*   **Data Analysis**: Identifies trends in data/text found on the page.

## 2. 💬 Context-Aware Chat
*   **Page Context**: The AI automatically reads the current web page, so you can ask questions like "What is the pricing mentioned here?"
*   **Streaming Responses**: Answers appear in real-time with a typing effect.
*   **Rich Formatting**: Supports **bold**, *italics*, lists, and code blocks.
*   **Highlighting**: The AI can highlight specific text on the webpage if asked (e.g., "Find where it talks about the battery life").

## 3. 📝 Intelligent Note Taking
*   **One-Click "Add to Notes"**: A button on every AI chat response automatically formats the text into a clean note and saves it.
*   **Smart Formatting**: The AI strips away conversational filler, "Source Excerpt" prefixes, and metadata tags, saving only the key facts.
*   **Note Management**: Users can delete individual notes or clear all notes for the current page.
*   **Enhanced Export**: 
    *   **PDF**: Generates a professionally formatted PDF with titles, proper spacing, and indented bullet points.
    *   **Word (.doc)**: Exports with rich HTML formatting preserved.
*   **Per-Page Memory**: Notes are saved specifically for the page you are viewing.

## 4. 🤖 Multi-Agent Architecture
The extension is powered by a sophisticated multi-agent system orchestrated by a **Master Agent**:
*   **Master Agent**: Coordinates all user requests and delegates tasks.
*   **Context Agent**: Handles page reading, caching, and text highlighting.
*   **Action Agent**: Executes specific use cases (Summarize, ELI5) and manages shared summary context.
*   **Chat Agent**: Manages the conversational flow, history, and context injection.
*   **Note Agent**: Specialized in formatting, saving, and managing user notes.

## 5. ⚡ Performance & Efficiency
*   **Parallel Execution**: Agents fetch dependencies (page content, history, summaries) concurrently for faster response times.
*   **In-Memory Caching**: Page context is cached in memory to avoid redundant processing during a session.
*   **Context Sharing**: Agents share context (e.g., the Chat Agent uses the summary generated by the Action Agent) to prevent redundant API calls and token usage.
*   **State Persistence**: Chat history and notes are saved via a robust mutex-queued storage system to prevent race conditions.

## 6. 🎨 Customization & UI
*   **Themes**: 9 different color accents (Indigo, Emerald, Rose, Orange, etc.).
*   **Appearance**: Toggle between **Light** and **Dark** modes.
*   **Window Size**: Adjustable popup size (Compact, Normal, Large).
*   **Typography**: Customize font family (Inter, Serif, Mono, etc.) and font size.
*   **Corner Style**: Choose between Rounded or Square UI elements.

## 7. ⚙️ Configuration
*   **Model Selection**: Switch between **Gemini 1.5 Flash** (Fast & Efficient) and **Gemini 1.5 Pro** (Reasoning & Complex Tasks).
*   **API Key Management**: Users can securely input and save their own Google Gemini API Key.
*   **Browser Tools**: Built-in actions to toggle **Reader View** or **Dark Mode** on the actual webpage.
